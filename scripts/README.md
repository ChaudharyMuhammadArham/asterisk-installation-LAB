# Installation Scripts

This folder contains two installation approaches.

## install.sh

Interactive installer.

Features:

- Automatic Installation
- Manual systemd Learning
- Learn Installation Steps

Recommended for most users.

---

## install-legacy.sh

Original sequential installation script.

This script performs:

- System update
- Dependency installation
- Download Asterisk
- Compile
- Install
- Install sample configuration
- Create systemd service using make config

Recommended for users who prefer a simple, direct installation process.
