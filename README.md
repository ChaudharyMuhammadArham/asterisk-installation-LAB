# asterisk-installation-LAB
Providing hands-on experience with real time troubleshooting techniques for, ''Asterisk PBX'' downloading, installation, compiling with help of 'PJSIP' configurations, dial-plan, troubleshooting and systemd services.

## Features

- Compile Asterisk from source
- Install dependencies
- Configure PJSIP endpoints
- Create a basic dial plan
- Configure a systemd service
- Verify installation
- Troubleshooting guide
- Useful CLI commands

## Tested Environment

- Ubuntu/Debian
- VMware Workstation
- Asterisk 20 LTS

## Repository Structure

install/
configs/
docs/
screenshots/
scripts/

## Lab Notes

The installation and configuration were completed successfully in a VMware-based lab environment. Due to virtualization networking restrictions, I was unable to perform end-to-end SIP call testing between softphones. The repository focuses on installation, configuration, endpoint registration, and troubleshooting.
